# Freq Demo Guide

## 🎯 Quick Start

1. **Access the App**: Navigate to http://localhost:3000
2. **Enter Beta Password**: Use `Freq420!` to access the app
3. **Authenticate**: Choose "Quick Beta Login" for testing
4. **Explore Features**: Switch between Inbox and Send tabs

## 🎤 Voice Messaging Demo

### Recording a Voice Message
1. Go to the **Send** tab
2. Search for users by typing in the search box
3. Select one or more recipients
4. Tap the microphone button to start recording
5. Speak your message
6. Tap the stop button to end recording
7. Preview your recording by tapping play
8. Send the message

### Receiving Voice Messages
1. Go to the **Inbox** tab
2. View received voice messages
3. Tap play to listen to messages
4. Delete unwanted messages
5. See sender information and timestamps

## 🔔 Notification System Demo

### Viewing Notifications
1. Click the bell icon in the header
2. Browse through different notification types:
   - 🎤 Voice messages
   - @ Mentions
   - ❤️ Reactions
   - 👤 Follows
   - 📝 Casts

### Notification Settings
1. Open the notification center
2. Click the settings icon
3. Toggle different notification types
4. Enable/disable push notifications
5. Request browser notification permissions

### Testing Notifications
1. Send a voice message to yourself
2. Check the notification center for the new notification
3. Mark notifications as read
4. Delete notifications
5. Clear all notifications
